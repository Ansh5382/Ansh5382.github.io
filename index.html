Machine learning · Deployed API credit-risk-api

Credit Default Risk API

Predicts whether a credit card customer will miss next month's payment, from six months of bills and repayments. Every answer comes with an approve or decline decision and the top reasons behind it.

  • LightGBM model trained on 24,000 real customers, compared against a logistic regression baseline
  • Per-customer explanations from SHAP values, grouped into plain reasons like "Late payments"
  • Sex, marital status and age left out of the inputs, with a fairness check across groups
  • FastAPI service with input validation, a browser demo, automated tests and a Docker image
